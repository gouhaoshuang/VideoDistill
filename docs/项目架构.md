## 核心模块

| 模块 | 文件 | 职责 |
|------|------|------|
| **GeminiClient** | `src/api/gemini_client.py` | Gemini API 封装，带 429 错误重试（指数退避，最多 5 次） |
| **NoteGenerator** | `src/core/note_generator.py` | 笔记生成流程编排，支持分段/直接两种模式 |
| **OutlineParser** | `src/core/outline_parser.py` | 解析 Markdown 大纲为章节列表（支持多种章节格式） |
| **VideoFileManager** | `src/storage/file_utils.py` | 基于哈希的缓存/恢复系统，支持断点续传 |
| **PromptTemplates** | `src/config/prompt_templates.py` | 加载 `src/prompts/*.txt` 提示词模板 |
| **BatchProcessor** | `src/batch/batch_processor.py` | 多线程并发批量处理，支持中断恢复 |
| **BatchTaskQueue** | `src/batch/task_queue.py` | 任务队列与状态管理（持久化到 JSON） |

## 生成模式

| 模式 | 适用场景 | 流程 |
|------|----------|------|
| **分段模式** (segmented) | 长视频 | 生成大纲 → 解析章节 → 逐章生成 → 合并 |
| **直接模式** (direct) | 短视频（默认） | 一次性生成完整笔记 |

## 缓存系统

视频通过哈希识别：`MD5(filename + filesize)[:12]`

- 每个唯一视频一个目录：`outputs/YYYYMMDD_hash/`
- 支持跳过已完成的步骤
- 支持恢复中断的分段生成
