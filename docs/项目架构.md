## 核心模块

### GeminiClient ([src/gemini_client.py](src/gemini_client.py))
- **职责**：封装 Google Gemini API 调用
- **主要类/函数**：
  - `GeminiClient`：API 客户端类
  - `generate_content()`：生成内容，带重试逻辑
  - `upload_file()`：上传文件到 Gemini
  - `delete_file()`：删除 Gemini 上的文件
- **特性**：
  - 自动处理 429 错误（指数退避，最多 5 次）
  - 可配置模型（gemini-3-pro-preview / gemini-3-flash-preview）
- **依赖**：`google.generativeai` SDK

### NoteGenerator ([src/note_generator.py](src/note_generator.py))
- **职责**：笔记生成流程编排
- **主要函数**：
  - `generate_outline()`：步骤 1，创建视频大纲
  - `parse_outline_to_segments()`：步骤 2，解析大纲为章节
  - `generate_segment_note()`：步骤 3，按章节生成笔记
  - `generate_all_notes()`：完整流程（支持模式选择）
  - `merge_notes()`：步骤 4，合并最终输出
- **生成模式**：
  - **分段模式**（segmented）：适合长视频
  - **直接模式**（direct）：适合短视频（默认）
- **依赖**：GeminiClient, OutlineParser, VideoFileManager

### VideoFileManager ([src/file_utils.py](src/file_utils.py))
- **职责**：基于哈希的缓存/恢复系统
- **主要类/函数**：
  - `VideoFileManager`：文件管理器类
  - `get_video_hash()`：计算 MD5(filename + filesize)[:12]
  - `get_video_dir()`：创建/获取视频输出目录
  - `get_temp_video_path()`：获取临时文件路径
  - `save_*()` / `load_*()`：各类文件存取
- **缓存策略**：
  - 每个唯一视频一个目录
  - 支持跳过已完成的步骤
  - 支持恢复中断的分段生成

### OutlineParser ([src/outline_parser.py](src/outline_parser.py))
- **职责**：解析 Markdown 大纲为章节列表
- **主要函数**：
  - `parse_outline_to_segments()`：提取章节标题和内容
- **支持的章节格式**：
  - "第一章"、"第1章"
  - "Chapter 1"、"CHAPTER 1"
  - "一、"、"1."
- **依赖**：正则表达式

### PromptTemplates ([src/prompt_templates.py](src/prompt_templates.py))
- **职责**：加载 AI 提示词模板
- **主要函数**：
  - `get_prompt()`：按名称加载提示词
- **模板来源**：`src/prompts/*.txt`

### 批处理模块

#### BatchProcessor ([src/batch/batch_processor.py](src/batch/batch_processor.py))
- **职责**：批量视频笔记生成器，多线程并发处理
- **主要类/函数**：
  - `BatchProcessor`：批处理器类
  - `process_files()`：批量处理视频列表
  - `resume()`：恢复中断的批量任务
  - `_write_summary()`：生成汇总报告
- **特性**：
  - 可配置并发线程数（max_workers）
  - 支持进度回调
  - 自动跳过已缓存的视频
  - 生成 batch_summary.md 汇总
- **依赖**：ThreadPoolExecutor, BatchTaskQueue, NoteGenerator

#### BatchTaskQueue ([src/batch/task_queue.py](src/batch/task_queue.py))
- **职责**：任务队列与状态管理，支持中断恢复
- **主要类/函数**：
  - `VideoTask`：任务数据类
  - `BatchTaskQueue`：队列管理器
  - `add_tasks()`：添加任务
  - `save()` / `load()`：状态持久化
  - `mark_*()`：状态标记（running/done/failed/skipped）
- **状态枚举**：PENDING, RUNNING, DONE, FAILED, SKIPPED
- **持久化**：`batch_status.json`

#### batch_main ([src/batch/batch_main.py](src/batch/batch_main.py))
- **职责**：批处理 CLI 入口
- **命令示例**：
  ```bash
  # 处理目录下所有视频
  python -m src.batch.batch_main --input videos/

  # 处理指定文件
  python -m src.batch.batch_main --input a.mp4 b.mp4

  # 恢复中断的批量任务
  python -m src.batch.batch_main --resume outputs/batch_20260225_120000

  # 指定模式和并发数
  python -m src.batch.batch_main --input videos/ --mode segmented --workers 4
  ```

## 数据流向

### Web UI 分段模式流程

```
1. 用户上传视频 (main.py)
   │
   ▼
2. VideoFileManager.get_video_hash()
   │
   ▼
3. 检查缓存 → 已有 outline.md？
   │                     │
   │ 否                  │ 是 → 跳过
   ▼                     ▲
4. NoteGenerator.generate_outline()
   │
   ▼
5. OutlineParser.parse_outline_to_segments()
   │
   ▼
6. 循环：NoteGenerator.generate_segment_note()
   │
   ▼
7. NoteGenerator.merge_notes()
   │
   ▼
8. 输出：outputs/YYYYMMDD_hash/final_notes.md
```

### Web UI 直接模式流程

```
1. 用户上传视频 (main.py → handlers.py)
   │
   ▼
2. UploadedFileHandler.save_uploaded_file()
   │
   ▼
3. NoteGenerator.generate_direct_note()
   │
   ▼
4. 输出：outputs/YYYYMMDD_hash/direct_note.md
```

### 批处理 CLI 流程

```
1. 用户执行 CLI 命令
   │
   ▼
2. batch_main.collect_videos()
   │
   ▼
3. BatchTaskQueue.add_tasks() → 保存 batch_status.json
   │
   ▼
4. BatchProcessor._run() → ThreadPoolExecutor
   │
   ▼
5. 循环：_process_single() → NoteGenerator.generate_all_notes()
   │     （每个线程处理一个视频）
   ▼
6. 每完成一个 → 更新 batch_status.json
   │
   ▼
7. 全部完成 → _write_summary() → batch_summary.md
   │
   ▼
8. 输出汇总：完成数、跳过数、失败数
```
