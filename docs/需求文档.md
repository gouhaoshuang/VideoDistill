# 需求文档

## 项目概述

VideoDistill 是一个基于 Python 的 AI 视频笔记生成工具，使用 Google Gemini AI。它通过 Streamlit Web 界面分析视频内容并生成结构化的 Markdown 笔记。

## 核心功能需求

### 1. 视频上传与处理
- **描述**：支持用户上传视频文件，自动计算文件哈希用于缓存识别
- **优先级**：高
- **验收标准**：
  - 支持最大 2GB 视频文件
  - 正确生成 MD5 哈希（filename + filesize）
  - 支持中文文件名

### 2. 大纲生成
- **描述**：AI 分析视频内容，生成结构化大纲
- **优先级**：高
- **验收标准**：
  - 大纲包含视频章节结构
  - 支持"第X章"、"Chapter X"等多种格式
  - 大纲保存到 `outputs/YYYYMMDD_hash/outline.md`

### 3. 分段笔记生成（默认模式）
- **描述**：按章节分别生成笔记，支持中断恢复
- **优先级**：高
- **验收标准**：
  - 自动解析大纲为章节列表
  - 每章独立生成笔记
  - 支持从任意章节恢复生成
  - 处理 API 429 错误（指数退避重试）

### 4. 直接笔记生成（短视频模式）
- **描述**：一次性生成完整笔记
- **优先级**：中
- **验收标准**：
  - 适用于短视频（<10分钟）
  - 输出单一 Markdown 文件

### 5. 缓存系统
- **描述**：基于哈希的视频缓存，避免重复处理
- **优先级**：高
- **验收标准**：
  - 重新上传相同视频时跳过已完成的步骤
  - 缓存元数据（metadata.json）
  - Gemini 文件过期提醒（48小时）

### 6. 笔记合并
- **描述**：将分段笔记合并为最终文档
- **优先级**：中
- **验收标准**：
  - 按顺序合并所有章节
  - 生成统一的 `final_notes.md`

## 技术栈

- **语言**：Python 3.11
- **Web 框架**：Streamlit
- **AI 服务**：Google Gemini 2.0 Flash
- **测试框架**：pytest
- **代码质量**：black, isort, ruff, pyright

## 非功能性需求

- **性能**：
  - API 请求失败最多重试 5 次
  - 指数退避策略处理速率限制

- **安全**：
  - API Key 仅通过环境变量设置
  - 不使用 .env 文件
  - 不硬编码敏感信息

- **可维护性**：
  - 测试覆盖率 80%+
  - 代码遵循 black/isort 格式规范
  - 类型检查通过 pyright
