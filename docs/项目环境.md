# 项目环境

> 最后更新：2026-03-04

## 环境概述

VideoDistill 使用 Conda 管理 Python 虚拟环境，确保开发与生产环境的一致性。

| 配置项 | 值 |
|--------|-----|
| 环境名称 | `videodistill` |
| Python 版本 | 3.11.x |
| 包管理器 | pip + conda |
| 虚拟环境路径 | `D:\develop\conda\envs\videodistill` |

---

## 快速开始

### 1. 创建并激活环境

```bash
# 创建 conda 环境（Python 3.11）
conda create -n videodistill python=3.11 -y

# 激活环境
conda activate videodistill
```

### 2. 安装依赖

```bash
# 安装项目依赖
pip install -r requirements.txt

# 或者使用 conda 运行（不激活环境时）
conda run -n videodistill pip install -r requirements.txt
```

### 3. 设置环境变量

```bash
# Windows PowerShell
$env:GOOGLE_API_KEY = "your-api-key-here"

# Windows CMD
set GOOGLE_API_KEY=your-api-key-here

# 永久设置（Windows 系统环境变量）
# 设置 → 系统 → 关于 → 高级系统设置 → 环境变量
```

### 4. 运行应用

```bash
# 方式一：激活环境后运行
conda activate videodistill
streamlit run main.py

# 方式二：使用 conda run（不激活环境）
conda run -n videodistill streamlit run main.py

# 方式三：使用批处理脚本（Windows）
.\run.bat
```

## 常用命令

### 环境管理

```bash
# 激活环境
conda activate videodistill

# 退出环境
conda deactivate

# 查看环境详情
conda info --envs

# 导出环境配置（备份）
conda env export > environment.yml

# 删除环境
conda env remove -n videodistill
```


## 备注

- **不推荐使用 `.env` 文件**：API Key 通过系统环境变量设置，避免意外提交到版本控制
- **Gemini 文件有效期**：上传的视频文件在 48 小时后过期
- **视频大小限制**：最大支持 2GB
- **编码**：所有文件使用 UTF-8，支持中文文件名
