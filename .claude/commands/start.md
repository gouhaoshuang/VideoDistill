# 启动命令 /start

## 描述
初始化会话，读取项目核心文档，了解当前项目状态。

## 执行步骤

### 1. 读取项目文档
读取 `docs/` 目录下的三个核心文档：

| 文档 | 用途 |
|------|------|
| [项目环境.md](../docs/项目环境.md) | 开发环境配置、依赖要求 |
| [项目架构.md](../docs/项目架构.md) | 系统架构、模块设计 |
| [项目状态.md](../docs/项目状态.md) | 当前进度、待办事项 |

### 2. 分析项目状态
- 理解当前项目结构和已完成的工作
- 识别进行中的功能和待办事项
- 注意任何阻塞问题或技术债务

### 3. 等待用户指令
完成文档读取和分析后，向用户简要总结当前状态，然后等待下一步指令。

## 使用示例

```
/start
```

## 注意事项

- 确保三个文档存在，如有缺失提示用户
- 重点关注 `项目状态.md` 中的 "当前阶段" 和 "待办事项"
- 如发现文档与代码不一致，建议用户更新文档
