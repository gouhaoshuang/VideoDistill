# init-docs - 初始化项目文档

此命令在项目根目录的 `docs/` 目录下自动创建三大核心文档模板。

## 功能说明

运行此命令后，AI 将创建以下文档：

```
docs/
├── 需求文档.md      # 明确"要做什么"
├── 项目状态.md      # 记录"做到哪了"（核心文档）
└── 项目架构.md      # 记录代码架构
```

## 文档说明

### 需求文档.md


明确项目要做什么：
- 项目概述
- 核心功能需求列表
- 技术栈说明
- 非功能性需求

### 项目状态.md（核心文档）

记录项目开发进度：
- ✅ 已完成功能
- 🔄 进行中任务
- 📋 待办事项

> **自动更新**：开发完成后运行 `/update-status`，AI 自动扫描代码并更新此文档。

### 项目架构.md

记录当前代码架构：
- 整体架构图
- 目录结构说明
- 核心模块职责
- 数据流向

## 使用方式

在项目根目录运行：

```
/init-docs
```

## 文档模板内容

### 需求文档.md

```markdown
# 需求文档

## 项目概述

[一句话描述项目是什么]

## 核心功能需求

### 1. [功能名称]
- **描述**：[功能说明]
- **优先级**：高/中/低
- **验收标准**：[如何验证完成]

## 技术栈

- **语言**：[编程语言]
- **框架**：[主要框架]
- **数据库**：[数据库类型]
- **AI/ML**：[AI模型或服务]

## 非功能性需求

- **性能**：[响应时间、吞吐量等]
- **安全**：[认证、授权、数据保护]
- **可维护性**：[代码规范、测试覆盖率]
```

```markdown

> 最后更新：YYYY-MM-DD

## 概览

- 总任务数：X
- 已完成：X
- 进行中：X
- 待办：X
- 完成率：XX%

## ✅ 已完成

### [功能模块名称]
- [x] [具体任务] (完成日期)
- [x] [具体任务] (完成日期)

## 🔄 进行中

### [功能模块名称]
- [ ] [具体任务] - [备注]
- [ ] [具体任务] - [预计完成日期]

## 📋 待办

### [功能模块名称]
- [ ] [具体任务] - 优先级：高
- [ ] [具体任务] - 优先级：中

## 🐛 已知问题

- [ ] [问题描述] - 严重程度：高/中/低

## 📝 备注

[其他需要说明的事项]
```

## 目录结构

```
项目根目录/
├── src/              # 源代码
│   ├── module_a/     # 模块 A
│   └── module_b/     # 模块 B
├── tests/            # 测试代码
├── docs/             # 文档
└── config.py         # 配置文件
```

  - `ClassName`：[说明]

- **依赖**：[依赖的其他模块]

## 数据流向

## 配置说明

## 后续维护

### 更新状态文档

开发完成后运行：

```
/update-status
```

AI 将自动：
1. 扫描最新代码变更
2. 分析已完成的功能
3. 更新任务状态
4. 添加新待办事项（如适用）

## 相关命令

- `/update-status` - 更新项目状态文档
- `/plan` - 创建实施计划
