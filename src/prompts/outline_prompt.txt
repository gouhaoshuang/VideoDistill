## 大纲格式要求

请严格按照以下 Markdown 格式输出：

```markdown
# [视频标题]

## 第一章：[第一段标题]
[第一段的内容概述，包括主要知识点、关键概念等]

---

## 第二章：[第二段标题]
[第二段的内容概述]

---

## 第三章：[第三段标题]
[第三段的内容概述]

[...继续添加更多章节...]
```

## 格式说明

1. **标题**：使用 `# ` 开头，后跟视频的主要标题
2. **章节标记**：必须使用 `## ` 开头的二级标题
3. **章节编号**：使用 `第一章`、`第二章` 或 `第1章`、`第2章` 格式
4. **分隔符**：章节之间使用 `---` 分隔（最后一章不需要）
5. **冒号**：章节编号和标题之间使用中文冒号 `：` 或英文冒号 `:`

## 分段原则

- 按视频的逻辑顺序或时间顺序分段
- 每段聚焦一个主题或一组相关概念
- 段落数量建议 3-8 段（根据视频长度和内容密度调整）
- 每段概述应包含该段的核心内容和要点

## 输出要求

- 只输出 Markdown 格式的大纲，不要添加其他说明文字
- 确保格式严格符合上述要求，便于后续自动解析
